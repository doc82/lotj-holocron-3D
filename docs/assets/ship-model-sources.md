# Star Wars ship model source list

This page preserves dated acquisition research and earlier evaluation results.
For current shipped models, start with the [asset index](README.md) and
[model catalog](../../renderer/src/domain/shipModelCatalog.json). Candidate and
"not found" lists below may have been superseded by original project models.

This is the working acquisition list for replacing Holocron's procedural ship
silhouettes. The project only needs ships in the `starfighter` category and
larger. Prefer downloadable GLTF/GLB models with explicit redistribution terms,
manageable polygon counts, and complete textures.

Star Wars names and designs remain Lucasfilm/Disney intellectual property. A
Creative Commons license covers the contributing artist's model work; it does
not grant rights to the underlying franchise. Keep Holocron unofficial, include
per-asset attribution, and do not assume that a downloadable or paid model may
be redistributed without an explicit license.

## Runtime assignment strategy

The authoritative classification for every downloaded model is
`renderer/src/domain/shipModelCatalog.json`. Each entry declares one model ID,
display name, ship category, source file, scale, optimization budget, and all
known class/name aliases. Runtime assignment is deliberately deterministic:

1. **Explicit name:** an exact normalized ship name in `exactNames` wins over
   every other signal. Use this for a unique named ship that needs a special
   model regardless of its reported class.
2. **Exact alias:** match the reported class against a catalog alias, followed
   by the ship name. Punctuation, case, apostrophes, and hyphens are normalized.
3. **Partial alias:** search the class, followed by the name, using whole-token
   phrases. The longest alias wins, so `T-65B X-wing Starfighter` is preferred
   over `X-wing`. Equal-strength matches for different models are treated as
   ambiguous and skipped.
4. **Category fallback:** use the configured default model for `starfighter`,
   `freighter`, `gunboat`, `corvette`, `frigate`, `cruiser`, or `battleship`.
5. **Procedural fallback:** retain Holocron's procedural category model if no
   configured runtime mesh is available.

Current category defaults are X-wing, YT-2400, Firespray, CR90, Praetorian,
Quasar Fire, and Imperial-II respectively. `Pollution` remains the first
explicit named-ship override.
