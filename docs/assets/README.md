# Models, textures and attribution

## Current assets

The [ship catalog](../../renderer/src/domain/shipModelCatalog.json) is the source
of truth for model IDs, aliases, scale, attribution and release eligibility.
All 29 current entries are release eligible. Eight models use original project
geometry; the remaining models use attributed imported sources.

- [Original model notes](models/README.md): design references and individual previews.
- [Third-party asset notices](third-party-assets.md): attribution and usage restrictions.
- [Local asset workflow](../../vendor-assets/README.md): source directories, builds and private ZIPs.
- [Release handoff](../releases/README.md): private bundle validation and distribution.
- [Ship acquisition and research](ship-model-sources.md): dated inventory and candidate history,
  not a definitive list of models still missing.

Runtime assets and review GLBs are generated outside Git. Preview materials do
not replace Holocron's tactical faction shading.
