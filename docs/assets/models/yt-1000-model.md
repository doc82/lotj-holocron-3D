# Original YT-1000 model, first pass

The original mesh is generated by `tools/models/yt-1000.mjs`. It is a hand-coded
interpretation for review, not an exact replica or a conversion of the downloaded
Ebon Hawk. No downloaded mesh or texture was used to generate it.

The shape uses a shallow saucer, a raised centerline cockpit, short cargo
mandibles, two rear engines, docking collars, cooling louvres, and radial hull
plates. The general arrangement was checked against the
[YT-1000 scratch-build reference](https://gattaca67.blogspot.com/2012/09/yt-1000-part-1-shaping-yt-1000.html).
Dimensions and surface details are artistic approximations. No weapon loadout
is implied by this base hull.

## Review and edit

Run `pnpm review:ships` to rebuild the local meshes and generate three-view PNGs
of the Naboo, JumpMaster, and YT-1000 under `vendor-assets/ships/review/`.
This works offline with the existing downloads and does not contact the relay
or replace live ship telemetry. The same directory contains `yt-1000.glb`, with
named parts, flat normals, and simple hull/glass/exhaust materials; it can be
imported into Blender or another glTF editor. The PNGs render the actual mesh
with a depth buffer, not a generated concept illustration.

Edit the procedural source to keep geometry changes reproducible. The ship
asset cache includes that source, so edits invalidate the next build. The
generator is independent of Blender and requires no extra installed software.
Generated meshes and review exports are ignored by Git; the generator is the
authoritative source.

The model uses +Y up and +Z forward. Runtime geometry matches the GLB, but the
current tactical renderer applies its own geometry-only faction shading: the
GLB's preview colors and downloaded Naboo textures are not rendered in-game.
The model is assigned to YT-1000 aliases only; the YT-2400 and general freighter
fallback remain unchanged. Both Naboo names share one N-1 mesh.

Original project geometry is identified separately from third-party Creative
Commons assets. This does not grant rights to underlying Star Wars IP.
